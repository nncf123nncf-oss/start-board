# 仕事をはじめる1画面（start-board）

毎朝使うツールのリンクと、その日のメモを1画面に並べる1ページの道具です。

1. よく使うリンクを、用途ごとのまとまり（例「毎朝ひらく」「お金」「つくる」）に分けてボタンで並べます（まとまり6つ・1つのまとまりにリンク12個まで）
2. まとまりごとに「まとめて開く」。ブラウザが2つ目以降を止めたときは「次を開く（2/5 …）」で1つずつ開けます。iPhone・iPadでは最初から1つずつ開きます
3. 同じ画面に「今日のメモ」。打つと0.5秒後に保存され、日付ごとに新しい30日分が残ります
4. 別の端末へは「設定を文字でコピー」で、まとまりとリンクを英数字の文字（`SB1.…`）にして運びます（メモは移りません）

- 登録したリンクとメモは、お使いの端末のブラウザ（localStorage）にだけ保存します。ブラウザのデータを消すと消えます。読み取れなかった保存データは、日時つきの別のキーに新しい3回ぶんまで残します
- 登録できるのは `http:`・`https:` のアドレスだけです。`https://` が抜けていたら、付けた形を見せて確かめます
- サイトのアイコンを外部のサービスから取ってきません（ボタンの印は名前の頭文字です）
- ログイン・アカウント・サーバーは使いません。閲覧数の計測に Cloudflare Web Analytics を使っています
- 確認は確認ダイアログではなく、画面の中のボタンで行います（アプリ内ブラウザで確認ダイアログが出ない場合に備えて）
